## 프로토스 한국어 메모
- 한국어 자료에서는 **관문 더블**을 공통 정석 출발로 자주 설명합니다.
- 프테전 관련 한국어 빌드명으로는 `거사조`, `510 예언자`, `패스트 암흑 기사`, `빠른 2거신뽕`, `분광사도` 같은 표현이 반복됩니다.
- 프저전 관련 빌드명으로는 `공허 트리플`, `예언자 트리플`, `3관문 6파수기 트리플`, `황금 함대` 등이 자주 등장합니다.
- 한국어 표현으로 보면 프로토스는 **점멸·거신·관측선·분광기·고위기사 연결**이 자연스러운 복기 포인트입니다.
- 따라서 자동 분석에서는 영어 유닛명보다 `점멸`, `로봇공학 시설`, `관측선`, `분광기`, `사이오닉 폭풍` 같은 단어를 우선 사용합니다.

## 테란 한국어 메모
- 한국어 자료에서는 공허의 유산 이후 테란 빌드를 `1/1/1 체제`, `사신 더블`, `병영 더블`, `지뢰드랍`, `은폐 밴시`, `메카닉`, `사이클론 트리플` 등으로 설명합니다.
- 테저전/테프전 분석에서 자주 쓰는 핵심 표현은 `자극제`, `전투방패`, `충격탄`, `공성전차`, `의료선`, `우주공항`, `유령`입니다.
- 한국어 커뮤니티식 복기 포인트는 보통 **첫 정찰 → 첫 압박 타이밍 → 3사령부/업그레이드 연결 → 진출 타이밍** 순서입니다.
- 따라서 자동 분석에서는 `보병 공업`, `보병 방업`, `자극제`, `전투방패`, `공성전차`, `유령 사관학교` 같은 번역어를 사용합니다.

## 저그 한국어 메모
- 한국어 자료에서는 저그의 뼈대를 `선부화장`, `선발업`, `16·17 부화장`, `18못`, `6여왕` 같은 출발 표현으로 설명합니다.
- 조합 이름도 한국어 약칭이 강합니다. 예: `뮤링링`, `히링링`, `바드라`, `바멸충`, `무감타`.
- 저테전/저프전 복기에서는 `점막`, `여왕 위치`, `저글링 발업`, `맹독충 둥지`, `번식지`, `포자 촉수` 같은 단어가 해설에 더 자연스럽습니다.
- 따라서 자동 분석에서는 `저글링 발업`, `맹독충 속업`, `맹독충 둥지`, `번식지`, `바퀴 소굴`, `가시지옥 굴` 같은 표현을 우선 사용합니다.

## 분석 문체에 반영할 한글화 원칙
- `PvT`, `ZvT` 같은 표기는 유지하되, 본문에서는 되도록 `프테전`, `저테전` 같은 한국어 매치업 표현을 함께 씁니다.
- `BlinkTech`, `Stimpack`, `RoboticsFacility` 같은 원문 이벤트명은 그대로 노출하지 않고 `점멸`, `자극제`, `로봇공학 시설`처럼 바꿔 씁니다.
- 한국어권 유저가 실제 복기할 때 익숙한 표현(예: `잘 짼 뒤 교환을 비싸게 했다`, `보조 체제가 늦었다`, `점막 연결이 끊겼다`)을 우선 사용합니다.
- 주의: 위키 기반 빌드명은 오래된 것도 많으므로, 자동 분석에서는 **현재 메타 정답**으로 단정하지 않고 **복기 언어와 개념어 보정용**으로만 활용합니다.
