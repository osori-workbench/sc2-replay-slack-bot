# Zerg guide distilled context

> 패치, 맵풀, 유행 빌드에 따라 세부 보급/초 단위는 흔들린다. 이 문서는 **고정 빌드표**보다 **래더에서 반복되는 안정적 판단 규칙**을 우선한다.

## Core ladder principles
- 저그의 핵심 질문은 항상 하나다: **지금 드론을 더 째도 되는가, 아니면 애벌레를 병력으로 바꿔야 하는가**.
- 기본 출발선은 보통 **16 Hatch / 18 Gas / 17 Pool**. 단, 빌드보다 중요한 것은 **정찰 후 생산 전환 시점**이다.
- 저그는 한 번 과하게 째면 즉사하고, 반대로 상대가 안 치는데 병력을 과투자하면 운영이 무너진다.
- 여왕, 점막, 대군주 시야는 단순 보조가 아니라 **생산 판단을 가능하게 하는 정보 인프라**다.
- 리플레이에서 먼저 볼 것은 컨트롤보다도  
  **1) 정찰이 됐는지 2) 그 정보에 맞게 드론/병력 비율을 바꿨는지 3) 테크 연결이 안 끊겼는지**다.

## Universal scouting / transition checkpoints
### 공통 체크 타임
- **0:00~2:00**: 첫 대군주로 앞마당/전진 건물/치즈 경로 확인.
- **2:00~3:30**: 여왕 수, 저글링 발업, 3베이스, 대군주 배치 정리.
- **3:30~5:00**: 두 번째 대군주나 저글링 희생으로 **본진 테크/3멀티 유무/가스 수** 확인.
- **5:00~7:00**: 상대 체제 확정 후 **맹독충 둥지 / 바퀴 소굴 / 번식지 / 진화장 / 히드라 / 둥지탑** 중 무엇을 먼저 연결할지 결정.
- **7:00 이후**: 4멀티, 업그레이드, 군락, 살모사/가시지옥/울트라/무리군주 같은 고급 전환 준비.

### 공통 의사결정 규칙
- 상대가 **2베이스 + 가스 많음 + 3멀티 지연**이면 드론 과욕 금지. 심시티, 여왕, 가시촉수/포자촉수, 병력 우선.
- 상대가 **빠른 3멀티 + 얕은 테크**면 드론과 업그레이드 욕심을 더 내도 된다.
- 포자촉수는 “손해 같아 보여도”  
  **밴시 / 예언자 / 빠른 공중 / 뮤탈 징후**가 있으면 늦게 짓는 것보다 낫다.
- 감시군주, 변신수, 대군주 희생은 저그에게 소모가 아니라 **생산 최적화 비용**이다.
- 리플레이에서 “왜 졌지?”가 아니라 **어느 체크포인트에서 정보가 끊겼는지**를 찾는다.

## ZvT
### 핵심 질문
- **4~5분 안에** 반드시 구분: **2-1-1 / 1-1-1 / 화염차 압박 / 밴시 / 해방선 / 전순 / 메카닉**.

### 정찰 체크
- 4분대 대군주 찌르기로 **군수공장 수, 우주공항 부속건물, 3사령부 타이밍** 확인.
- 의료선 경로, 화염차 진입각, 본진 공중 견제 루트에 대군주를 분산.
- 테란이 조용하다고 안전한 게 아니다. **우주공항 기술실 + 지상 병력 적음**은 은폐/전순 경보다.

### 대응 규칙
- **2-1-1**: 여왕 숫자와 위치가 핵심. 저글링만 많이 찍으면 드랍 반복에 말린다.  
  점막 위 교전, 본진-앞마당 분산 배치, 의료선 점사 우선.
- **1-1-1 화염차/밴시/해방선**: 입구 여왕, 포자촉수 타이밍, 광물 라인 반응 속도 점검.
- **바이오닉**: 링링+여왕으로 버티며 업그레이드와 점막을 넓힌다. 점막 밖 추격은 금물.
- **메카닉**: 바퀴·궤멸충은 “중간 다리”일 뿐이다.  
  군락 전환 계획 없이 바퀴만 쌓으면 후반에 압사당한다.  
  살모사 납치/흑구름, 가시지옥, 군단숙주, 무리군주 축을 미리 설계.
- **전순**: 포자촉수+여왕으로 시간 벌기, 이후 타락귀 여부 판단.  
  첫 전순 막고 드론만 찍다가 2전순·3전순에 다시 터지는지 확인.

### ZvT replay review flags
- 5분 전후 의료선 타이밍 전에 여왕이 제자리였는가?
- 화염차를 점막 밖까지 쫓아가며 저글링을 헌납했는가?
- 메카닉 확인 후에도 번식지/군락/살모사 계획이 늦었는가?
- 드랍 경로 시야가 없어서 “반응이 늦은” 패배였는가?

## ZvP
### 핵심 질문
- 프로토스의 분기: **우주관문(우관) / 황혼의회 / 로공 / 빠른 3넥서스 / 광자포 러시 / 스카이토스**.

### 정찰 체크
- **인공제어소 업그레이드**가 자연스럽지 않으면 우관 가능성 상승.
- **관문 시간증폭 반복**은 사도 압박, 특히 공명사도 신호로 본다.
- **2베이스 가스 많음 + 3넥 지연**이면 돌진, 불멸자, 분광기 올인 우선 의심.
- 앞마당 수정탑·제련소·탐사정 수는 광자포 러시 판단 재료.

### 대응 규칙
- **우관 개막**: 본진/앞마당 포자촉수 1개, 여왕 위치 조정, 대군주 손실 최소화.  
  예언자 막고 드론을 계속 째는지, 괜히 과잉 병력으로 말리는지 체크.
- **황혼/공명사도**: 저글링 추가, 바퀴 소굴 준비, 입구 심시티.  
  사도를 쫓느라 병력 흩어져 광물 피해가 커지는 패턴 주의.
- **돌진/불멸자/분광기 올인**: 드론 중단, 바퀴·궤멸충 중심, 필요시 맹독충.  
  분광기 점사와 배터리 제거가 핵심.
- **스카이토스**: 타락귀만 찍는 단순 대응 금지.  
  여왕+포자촉수로 시간 확보 후 **타락귀 / 감염충 / 살모사 / 히드라**를 지상 상황에 맞춰 섞는다.
- **광자포 러시**: 건설 중 수정탑은 일벌레로 즉시 끊고, 이미 자리 잡혔으면 바퀴·궤멸충 전환으로 철거.

### 실전 타이밍 옵션
- 우관 상대로는 **여왕 중심 안정 운영** 후 3베이스 최적화가 기본.
- 프로토스가 과하게 째거나 우관으로 배를 불리면 **55 드론 바궤링 여왕 드랍**, **트리플 바궤뽕** 같은 타이밍 압박이 유효.
- 단, 타이밍 빌드는 리플레이에서 **드론 컷 시점**과 **대군주 수송/속업 연결**이 맞았는지로 평가한다.

## ZvZ
### 핵심 질문
- 초반은 **링링 안전화**, 중반은 **바퀴·궤멸충**, 이후는 **뮤탈/가시지옥/후반 테크 전환 감지**다.

### 정찰 체크
- 상대 앞마당 유무와 드론 수.
- 빠른 **맹독충 둥지 / 바퀴 소굴 / 진화장 / 번식지 / 둥지탑**.
- 저글링이 갑자기 안 보이거나 대군주가 연속으로 끊기면 공격 신호로 본다.
- ZvZ는 “정보 없음 = 안전”이 아니라 **정보 없음 = 더 위험**인 경우가 많다.

### 대응 규칙
- **12못/링 올인**: 드론 과욕 금지, 여왕·저글링·가시촉수로 안정화.
- **링링 단계**: 입구 심시티, 맹독충 분산, 저글링 뭉침 금지.
- **바퀴 전환**: 2~3베이스 드론을 채우되 상대보다 늦은 소굴/업글이면 밀리기 쉽다.
- **빠른 뮤탈**: 타이밍이 남아 있으면 바퀴로 압박, 놓쳤으면 포자+여왕+히드라/감염충.
- **가시지옥전**: 살모사 납치/흑구름, 맞가시지옥, 궤멸충 담즙, 다방향 견제가 중요.
- **후반**: 울트라, 무리군주, 가시지옥은 정면 A-move보다 **시야와 위치 선점** 싸움이다.

## Common replay review mistakes
- 정찰을 했는데도 해석을 안 함: 본 건 많은데 드론을 계속 짼다.
- 정찰을 안 해서 병력을 찍었는데, 상대는 그냥 멀티 중이었다.
- 포자촉수/가시촉수를 너무 아끼다 첫 견제에 드론이 무너진다.
- 메카닉, 스카이토스, 뮤탈 전환을 봤는데도 **중간 조합에 고착**된다.
- 점막이 짧아 여왕/병력 회전이 늦고, 결과를 “교전 컨트롤 문제”로만 착각한다.
- 드론 컷 시점이 애매하다: 올인도 아니고 운영도 아닌 어중간한 상태로 진다.
- 패배 원인을 “빌드가 구림”으로 뭉뚱그린다. 실제 원인은 대개  
  **정찰 실패 / 드론 과욕 / 병력 과잉 / 테크 지연 / 드랍 반응 지연 / 점막 부족** 중 하나다.

## Korean terms / build names
- **째기**: 드론 중심으로 경제를 늘리는 것
- **드론 컷**: 특정 시점부터 드론 생산 중단
- **선부화장 / 선앞 / 16 Hatch**: 빠른 멀티 출발
- **18가스 17못**: 표준 저그 경제 오프닝
- **발업링**: 저글링 속도 업그레이드 기반 운영
- **링링**: 저글링+맹독충
- **바궤 / 바궤링**: 바퀴+궤멸충(+저글링)
- **히링링**: 히드라+저글링+맹독충
- **여왕 드랍**: 수송 대군주로 여왕을 실어 점막·수혈·화력 압박
- **트리플 바궤뽕**: 3베이스 기반 바퀴·궤멸충 타이밍
- **2-1-1**: 병영2 군수1 우공1 기반 해병·의료선 압박
- **1-1-1**: 병영1 군수1 우공1 기반 다목적 테란 테크
- **배틀메카닉**: 사이클론/화염차 계열 기동 메카닉
- **우관**: 우주관문 개막
- **공명사도**: 황혼의회 공명파열 사도 압박
- **스카이토스**: 공중 위주 프로토스 조합
- **12못**: 초반 산란못 러시
- **링링올인**: 저글링·맹독충 초반 올인
- **뮤탈 전환**: 중반 둥지탑 후 뮤탈리스크 전개
- **가시지옥 운영**: 러커 기반 위치 장악전

## One-line coaching summary
- 저그 리플레이는 “컨트롤이 나빴다”보다 **정찰 체크포인트를 놓쳐 드론/병력/테크 전환이 어긋났는가**를 먼저 본다.
