# Zerg guide distilled context

## Core ladder principles
- 기본 골격은 선부화장 기반 경제 출발, 빠른 정찰, 3베이스 최적화, 상대 체제별 병력 전환입니다.
- 저그는 "언제까지 드론을 째고 언제부터 병력을 찍는가"가 핵심 판단입니다.
- 정찰 실패 시 과한 째기 또는 과잉 수비 둘 다 치명적입니다.

## Universal checkpoints
- 16 Hatch / 18 Gas / 17 Pool 계열 경제 출발을 기준선으로 둡니다.
- 첫 대군주, 두 번째 대군주, 초기 저글링, 이후 감시군주/변신수까지 정찰 루프를 끊기지 않게 유지합니다.
- 3:30~5:00 사이 상대 본진/테크/3멀티 여부 확인이 중요합니다.

## ZvT
- 4~5분 사이 2-1-1, 1-1-1, 화염차, 밴시, 해방선, 전순, 메카닉 여부를 확정해야 합니다.
- 2-1-1 대응은 여왕 위치, 점막 연결, 드랍 경로 시야가 핵심입니다.
- 메카닉 확인 시 단순 바퀴 누적보다 군락/살모사/가시지옥/군단숙주 전환 계획이 중요합니다.

## ZvP
- 우관/황혼/로공/빠른 3넥 타이밍 판별이 핵심입니다.
- 프로토스가 2베이스 가스를 많이 먹고 3넥이 늦으면 올인 가능성을 우선 의심합니다.
- 스카이토스 징후면 여왕+포자촉수로 시간을 벌고 타락귀/감염충/살모사 전환을 준비합니다.

## ZvZ
- 초반 링링 안정화 후 바퀴/궤멸충 운영으로 넘어가는 흐름이 기본입니다.
- 상대 앞마당 드론 수, 맹독충 둥지, 바퀴 소굴, 둥지탑 타이밍을 지속 확인합니다.
