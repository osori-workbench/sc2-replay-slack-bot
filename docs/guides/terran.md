# 테란 리플레이 분석 가이드

> 패치, 맵, 유행 빌드에 따라 세부 수치는 바뀐다. 아래 내용은 특정 버전의 정답표가 아니라 **래더에서 오래 유지되는 판단 기준** 위주로 정리한다.

## 1. 코어 래더 원칙
- **한 경기의 승패는 빌드 이름보다 생산 연속성으로 결정된다.**
  - 2베이스 포화 전까지 SCV 끊김 최소화
  - 병영/군수공장/우주공항 유휴시간 최소화
  - 궤도 에너지는 평소 지게, 위험 시 스캔으로 전환
- **초중급 기본 골격은 `1병영 더블 → 1-1-1 또는 3-1-1 → 5-1-1/3기지`**
  - 세 종족전 공통 학습축으로 좋음
  - 오프닝보다 중요한 것은 `자극제 + 의료선 + 1공업` 첫 타이밍을 맞추는 것
- **견제는 이득용이 아니라 정보+템포용으로 본다.**
  - 사신: 킬 욕심보다 앞마당/가스/테크 확인
  - 지뢰드랍: 생산 멈추며 억지 컨트롤하면 손해
  - 화염차: 점막 제거, 저글링 억제, 드론 강제 반응
- **테란 교전의 핵심은 정면 힘이 아니라 진형 완성도**
  - 전차 시야, 바이킹 제공권, 의료선 생존, 후퇴 경로
  - 점막/언덕/좁은 입구/드랍 경로를 항상 함께 봄
- **심시티는 실수 방지 장치**
  - 저그전: 링 난입 방지
  - 토스전: 사도/광전사 진입 차단
  - 테테전: 사신 점프 경로, 벙커/전차 자리 확보

## 2. 공통 정찰·전환 체크포인트
### 시간대 체크
- **1:30**
  - 궤도 완성 지연 여부
  - 첫 유닛 생산 시작 여부
- **2:30**
  - 앞마당과 군수공장 동시 진행 여부
  - 가스가 남는데 테크가 늦는지 확인
- **3:30**
  - 우주공항/3병영 등 방향 확정
  - 정찰이 비면 스캔 또는 사신으로 보강
- **5:00**
  - 자극제, 의료선, 3CC 중 최소 하나가 파워스파이크 형성
  - 보급막힘/생산 공백이 가장 자주 발생하는 구간
- **6:30**
  - 첫 진출 또는 방어 완성
  - 업글/의료선/병력 숫자가 함께 맞는지
- **8:00+**
  - 3기지 활성화, 5병영 이상, 2업 단계 진입
  - 견제보다 생산/업글/재집결이 우선

### 정찰 질문
- 상대 **앞마당 타이밍** 정상인가?
- **가스 수**가 평소보다 빠른가?
- **관문/병영/부화장/공장 숫자**가 적거나 과한가?
- **은폐 징후**가 있는데 스캔/포탑/탐지가 준비됐나?
- 상대 3멀티가 빠르면 **내 첫 압박 타이밍**이 살아 있는가?

### 전환 규칙
- 정보가 부족할수록 **무리한 3CC보다 안전 유닛** 우선
- 자원이 남으면 컨트롤 실수보다 먼저 **생산건물 부족** 의심
- 진출 판단은 “병력 많음”이 아니라 **업글/의료선/시야** 기준으로 함

## 3. TvZ 체크포인트
### 기본 구조
- 추천 축: **사신 더블 → 화염차/바이킹(or 밴시) → 빠른 3CC → 바이오닉**
- 목표: 점막 확장 억제, 저그 애벌레 폭발 지연, 내 3기지 안전화

### 반드시 볼 신호
- **앞마당 없음/매우 느림** → 1베이스 링·맹독 의심, 벙커·수리·해병 지속
- **2가스 + 3부화장 없음** → 바퀴/궤멸충 압박 가능성, 전차/사이클론/밴시 준비
- **빠른 번식지/둥지탑** → 뮤탈 경계, 포탑·해병 배치·지뢰/토르 검토
- **점막 과확장** → 중반 교전력 상승, 화염차/스캔으로 반드시 정리
- **군락/살모사** → 유령, 바이킹, 전차 라인 강화

### 운영 규칙
- 점막 위 정면 교전은 최대한 피함
- 화염차는 드론 몇 기보다 **점막 제거 시간**이 더 중요할 때가 많음
- 첫 자극제 타이밍은 “킬각”보다 **저그 4베이스 속도 늦추기** 목적
- 후반은 해불의지 + 전차 + 유령의 진형 싸움으로 봄
- 패치/메타가 바뀌어도 **저그전 핵심은 3CC 안정화와 점막 관리**가 거의 항상 남음

## 4. TvP 체크포인트
### 기본 구조
- 추천 축: **1-1-1 지뢰드랍 → 3-1-1 또는 5병영 타이밍**
- 목표: 탐사정 피해, 토스 시선 분산, 3병영 자극제/공1업 타이밍 형성

### 반드시 볼 신호
- **빠른 우관** → 예언자/불사조, 해병 분산·사이클론·포탑
- **황혼의회 + 점멸** → 벙커·전차·지뢰·건물수리
- **로공** → 분광기/거신/불멸자, 바이킹·전차·지뢰 강화
- **암흑성소 의심** → 스캔 에너지 비축, 포탑, 밤까마귀 고려
- **빠른 3멀티** → 무리한 올인보다 자극제/공1업 압박, 3멀티 찌르기

### 운영 규칙
- 지뢰드랍은 “반드시 대박”보다 **본진 생산 유지**가 우선
- 토스전 수비는 병력 종류보다 **시야 없는 곳의 분광기 경로 차단**이 중요
- 거신/고위기사 체제로 갈수록 바이킹/EMP 가치 상승
- 정면 한방만 보지 말고 **드랍 + 정면 압박**으로 토스 병력 분산 유도
- 광자포 러시는 완성된 포보다 **건설 중 수정탑/광자포 끊기**가 핵심

## 5. TvT 체크포인트
### 기본 구조
- 추천 축: **더블 가스 사신/화염차 → 전차·바이킹·밤까마귀**
- 목표: 시야 선점, 전차 자리 선점, 제공권 유지

### 반드시 볼 신호
- **앞마당 없음 + 사신 다수** → 전진 병영/1베이스 압박 가능성, 벙커·수리
- **빠른 군수공장/우주공항** → 은밴/해방선/지뢰드랍, 스캔·포탑·바이킹·밤까마귀
- **전차 많고 진출 느림** → 수비형 3CC/메카닉, 정면 박기보다 따라가며 운영
- **바이오닉 집중** → 전차 위치·지뢰·의료선 낚시 주의
- **밤까마귀 다수** → 분산 진형, 방해매트릭스 각도 관리

### 운영 규칙
- TvT에서 바이킹은 딜 유닛보다 **전차 시야 유닛**
- 전차 숫자보다 **누가 먼저 보고 먼저 쏘는가**가 더 중요
- 언덕 아래 진출, 시야 없는 전진, 의료선 과투자는 흔한 패배 패턴
- 초보자는 불곰 더블 메카닉도 가능하지만, 드랍 대응과 제공권 관리를 놓치면 무너짐

## 6. 리플레이 리뷰에서 자주 나오는 패배 원인
- 사신/드랍 컨트롤 중 **본진 생산 정지**
- 46/62/86 전후 **보급 막힘**
- 지게/스캔 판단이 없음: 에너지 과다 또는 은폐 대응 실패
- 3CC 욕심으로 초반 압박에 **방어 유닛 부족**
- 자극제, 전투방패, 1공업, 2의료선이 안 맞는데 **억지 진출**
- 점막 위 교전, 시야 없는 언덕 진출, 전차 없이 해불만 돌진
- 상대 3멀티를 봤는데도 **타이밍 압박 없음**
- 견제는 열심히 했지만 정작 **업그레이드/생산시설/SCV 수가 뒤처짐**
- 패배 원인을 “컨트롤”로만 넘기고 **정찰 실패/전환 실수**를 놓침

## 8. 한 줄 결론
- **테란 리플레이는 “무슨 빌드였나”보다 `5분까지 생산`, `정찰 후 무엇을 눌렀나`, `첫 타이밍이 업글·의료선과 맞았나` 세 가지만 먼저 보면 대부분의 패인이 드러난다.**
