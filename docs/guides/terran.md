# Terran guide distilled context

## Core ladder principles
- 가장 안정적인 학습 축은 1병영 더블 이후 1-1-1 또는 3-1-1 바이오닉 운영입니다.
- 초반에는 빌드 디테일보다 SCV 생산, 보급 막힘 방지, 생산 건물 비우지 않기가 우선입니다.
- 첫 사신은 킬보다 정보 확인이 우선입니다.

## Universal checkpoints
- 14 Depot / 16 Barracks / 16 Refinery 계열이 범용 출발점입니다.
- 자극제, 2의료선, 1공업 같은 파워 스파이크와 진출 타이밍을 맞춰야 합니다.
- 패치상 전차 라인 유지, 바이킹 제공권, 지뢰 반응 속도, 유령 인구 효율이 좋아졌다는 점을 반영합니다.

## TvZ
- 사신 더블 → 화염차/바이킹 → 빠른 3사령부가 대표 경제형 기본 빌드입니다.
- 저그 점막 확장과 3베이스를 늦추는 것이 핵심입니다.
- 빠른 뮤탈/군락 징후면 포탑, 해병 배치, 유령/전차 라인 보강이 중요합니다.

## TvP
- 1-1-1에서 지뢰/밴시/해병탱크 압박 또는 3-1-1 수렴이 기본 축입니다.
- 프로토스의 관측선, 점멸, 거신 타이밍을 의식해 시야 싸움을 해야 합니다.
- 드랍과 본진 생산을 동시에 굴리되, 생산이 멈추면 견제 가치가 급락합니다.

## TvT
- 전차, 바이킹, 시야 장악이 중요합니다.
- 제공권과 언덕/시야 싸움이 곧 교전 효율로 연결됩니다.
